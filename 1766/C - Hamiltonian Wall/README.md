In particular, he wants cell $$$(i, j)$$$ (the $$$j$$$-th cell in the $$$i$$$-th row) to be colored black, if $$$c_{i, j} =$$$ '<span class="tex-font-style-tt">B</span>', and to be left white, if $$$c_{i, j} =$$$ '<span class="tex-font-style-tt">W</span>'.
